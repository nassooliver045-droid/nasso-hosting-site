# EsporteBet — demonstração

Protótipo visual de uma central esportiva em português brasileiro.

## Executar
- Requer Node.js 20+
- `npm start`

## Deploy no Render
- Runtime: Node
- Build command: `cd esportebet && npm install --omit=dev`
- Start command: `cd esportebet && npm start`
- Região sugerida: Ohio

## Limites desta versão
Esta aplicação é somente demonstrativa. Não possui cadastro de apostadores, carteira, pagamentos, saques, odds reais ou execução de apostas. Não habilite tais funções sem avaliação jurídica, licenças e controles regulatórios aplicáveis.
